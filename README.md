# PromptSift

Local-first CLI tool for versioning and managing AI prompts.

**Built by Mourad.Soltani**

## Features
- Add / update prompts with automatic versioning
- List, show, search prompts
- Local SQLite storage (~/.promptsift/)
- No external dependencies beyond Python stdlib
- Health tests included

## Installation
```bash
python3 src/promptsift.py --help
```

Or copy to PATH.

## Requirements
- Python 3.8+
